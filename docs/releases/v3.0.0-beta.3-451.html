PortPanic 3.0.0 Beta 3

- Warns when a camera connects slowly or its USB speed drops.
- Adds Air Raid and Losing Horn sounds with matching glow movement.
- Adds custom audio, an optional Loss timeout and a switch to hide the dialog.
- Adds an optional Buy Me a Coffee link in About.

This is a public beta for testing. Real-camera drop/recovery, extended shooting, fresh-install permissions, and macOS 14/Intel coverage are still being checked. Test with your own setup before relying on it during a shoot.
