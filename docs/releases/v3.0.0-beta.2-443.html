PortPanic 3.0.0 Beta 2

PortPanic 3.0.0 Beta 2, build 443

Daily update checks are now on by default. You can turn them off in Settings,
Monitoring. Your saved on/off choice is kept. You still choose when to install,
and updates wait while a camera is being watched or an alert test is running.

The download includes the visual drag-to-Applications installer with the USB-C
cable design and red and green edge light.

Install
Open the DMG, drag PortPanic to Applications and replace the previous copy.
Open it from Applications. Your settings and existing Capture One access are kept.
Requires macOS 14 or later and Capture One 16.x. Includes Apple silicon and Intel.

Please check Test Loss Alert, then try a real cable pull and reconnect with your
setup before a shoot. Real-camera timing, extended shooting, fresh-install
permissions, display/audio/keyboard behavior and macOS 14/Intel coverage are
still being checked. The Settings CPU fix still needs confirmation on the
affected macOS 26.3 machine.

Report problems
https://github.com/austinpresley/PortPanic-Releases/issues/new?template=bug_report.yml
Include your Mac, macOS, Capture One version, camera and cable/USB setup,
what you expected and what happened. Settings, Monitoring, Export Diagnostics
saves a file you can review and attach. It includes device names but no image
names or session paths.

PortPanic is free to use and share unmodified. Application source is private.
Bundled components retain their own licenses.

This is a public beta for testing. Real-camera drop/recovery, extended shooting, fresh-install permissions, and macOS 14/Intel coverage are still being checked. Test with your own setup before relying on it during a shoot.
