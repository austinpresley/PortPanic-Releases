PortPanic 3.2.0 Beta 1

- Pre-approve battery or camera swaps with an adjustable window and a global shortcut. Reconnects still play the normal Recovery alert.
- Add one Stream Deck key for live status, approval countdowns and alarm dismissal. Install it from Settings.
- See recent camera drops and reconnects in local history, with a clearer pre-shoot status check.
- Export and import settings, including your selected custom sounds.
- Get smarter USB speed warnings using documented specifications for 97 camera models.
- Optionally scale the glow to each display, with previews that match its proportions.
- Use a cleaner menu, plus improved USB drop detection and reconnect handling.

Known issue: with multiple cameras tethered, a reconnect can hide an overlapping camera drop.

This is a public beta for testing. Real-camera drop/recovery, extended shooting, fresh-install permissions, and macOS 14/Intel coverage are still being checked. Test with your own setup before relying on it during a shoot.
