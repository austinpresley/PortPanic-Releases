PortPanic 3.2.0 Beta 2

Changes since 3.2.0 Beta 1:

- Refined the menu and Settings layout. Disconnect actions stay in one place,
  Loss and Recovery controls match, and Dismiss options are grouped together.
- Simplified camera history, app controls and shortcut settings.
- Fixed a multi-camera reconnect case where another camera's pending drop
  could be forgotten. Its next confirming read now triggers the Loss alert.
- Fixed Camera History naming a camera as tethered on return when Capture One
  had not listed it in that reading.

Includes the signed PortPanic Control Stream Deck plugin 1.0.0.463. Install it
from Settings, Advanced, Install Stream Deck Plugin.

macOS 14 or later. Apple silicon and Intel. Free to use and share unmodified.

Real multi-camera timing, shooting-Mac appearance and controls, extended
shooting, fresh-install permissions and macOS 14/Intel runs remain pending.
Test the alert and take a test photo in Capture One before your first shoot.

This is a public beta for testing. Real-camera drop/recovery, extended shooting, fresh-install permissions, and macOS 14/Intel coverage are still being checked. Test with your own setup before relying on it during a shoot.
